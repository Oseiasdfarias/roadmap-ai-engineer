# Como contribuir

Nesta versão, a contribuição é feita só por **issues**. Pull requests com mudanças de conteúdo não são aceitos por enquanto, para manter a voz e o nível de revisão do roadmap.

## Sugerir uma correção

Achou um erro, uma informação desatualizada ou um trecho confuso? Abra uma issue com o modelo "Correção de conteúdo": https://github.com/Oseiasdfarias/roadmap-ai-engineer/issues/new/choose

Diga em qual página está, cite o trecho e, se puder, cole o link de uma fonte que confirme a correção.

## Avisar de um link quebrado ou sugerir uma referência

Use o modelo "Sugestão ou link quebrado". Para uma referência nova, explique o que o material ensina e para quem serve. Damos preferência a fontes gratuitas, oficiais e, quando existirem, em português.

## Antes de abrir

- Procure se já existe uma issue sobre o mesmo ponto.
- Uma issue por assunto.
- O conteúdo segue um guia editorial: texto direto, sem promessas de resultado e com fontes verificáveis.

Ao sugerir texto, você concorda que ele pode entrar no roadmap sob a licença CC BY 4.0 (veja `LICENSE-CONTEUDO.md`).
