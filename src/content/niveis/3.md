Este é o nível em que você constrói. Existem duas faces do trabalho de um AI Engineer, e o mercado pede as duas: construir soluções com IA para empresas e usar IA para construir software mais rápido.

## Por que este nível vem agora

Com a base e os conceitos prontos, você consegue revisar o que um agente de programação produz. Sem isso, a IA escreve código que você não sabe avaliar, e o portfólio vira uma demonstração que você não consegue defender numa entrevista.

Os projetos P1 a P4 cobrem as camadas de um sistema agêntico: conversa e ferramentas, RAG com busca híbrida, um servidor MCP com aprovação humana e um workflow de triagem. Todos usam dados públicos ou sintéticos.

## Como estudar este nível

Aprenda a usar o agente de programação pelos cursos oficiais, trabalhe sempre no ciclo planejar, implementar e revisar, e só faça commit do que você leu e entendeu. Comece pelo P1 e avance por camadas, marcando cada versão no Git.

Cada projeto precisa de README com o problema, a arquitetura, como rodar, as decisões técnicas e os resultados dos evals. Os prazos são indicativos: o nível costuma levar de 6 a 9 meses em paralelo com estudos ou trabalho, menos para quem já desenvolve software (veja a calculadora de trilha).
