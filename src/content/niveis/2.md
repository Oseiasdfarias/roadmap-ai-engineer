Este nível é de estudo e leitura, com pequenos experimentos. A construção vem no nível 3: aqui o objetivo é entender o papel de cada peça de um sistema agêntico antes de montá-las.

## Por que este nível vem agora

Separar teoria de prática evita um erro comum: aprender a encaixar peças de um framework sem saber para que servem. Quando algo falha, quem entende o conceito diagnostica; quem só copiou a configuração fica sem saber por onde começar.

O nível pode começar no fim do nível 1, assim que você já chama uma API de LLM com segurança. Ele trata de dois assuntos: como o sistema funciona (RAG, ferramentas, MCP, workflow ou agente, aprovação humana, contexto) e como mantê-lo bom e seguro (evals, guardrails, prompt injection, LGPD, custo e latência).

## Como estudar este nível

Para cada tópico, responda três perguntas: o que é, por que existe e quando não usar. Faça experimentos pequenos que tornem o conceito visível, como comparar a busca vetorial com a busca por palavra-chave num conjunto de textos seu.

Ao final, tente desenhar o mapa completo de um sistema agêntico de memória. Se não conseguir explicar uma camada, volte ao tópico correspondente. Os prazos são indicativos e dependem das horas semanais que você consegue dedicar.
